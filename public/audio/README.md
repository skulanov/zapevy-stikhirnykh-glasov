# Аудиофайлы запевов стихирных гласов

В эту директорию помещаются аудиозаписи запевов для 8 стихирных гласов.

## Формат именования файлов: `X-N.mp3`
- `X` — символ партии:
  - `S` — Сопрано (Soprano)
  - `A` — Альт (Alto)
  - `T` — Тенор (Tenor)
  - `B` — Бас (Bass)
  - `ALL` — Все партии сразу (Полный хор SATB)
- `N` — номер гласа от 1 до 8.

## Полный список из 40 файлов:
- **Сопрано**: `S-1.mp3`, `S-2.mp3`, `S-3.mp3`, `S-4.mp3`, `S-5.mp3`, `S-6.mp3`, `S-7.mp3`, `S-8.mp3`
- **Альт**: `A-1.mp3`, `A-2.mp3`, `A-3.mp3`, `A-4.mp3`, `A-5.mp3`, `A-6.mp3`, `A-7.mp3`, `A-8.mp3`
- **Тенор**: `T-1.mp3`, `T-2.mp3`, `T-3.mp3`, `T-4.mp3`, `T-5.mp3`, `T-6.mp3`, `T-7.mp3`, `T-8.mp3`
- **Бас**: `B-1.mp3`, `B-2.mp3`, `B-3.mp3`, `B-4.mp3`, `B-5.mp3`, `B-6.mp3`, `B-7.mp3`, `B-8.mp3`
- **Все партии (Хор)**: `ALL-1.mp3`, `ALL-2.mp3`, `ALL-3.mp3`, `ALL-4.mp3`, `ALL-5.mp3`, `ALL-6.mp3`, `ALL-7.mp3`, `ALL-8.mp3`

*Примечание: Если файл отсутствует, приложение автоматически синтезирует аутентичный 4-голосный московский обиходный распев с помощью встроенного Web Audio API синтезатора.*
