# Запевы стихирных гласов (zapevy-stikhirnykh-glasov)

Интерактивный тренажёр и справочник по запевам восьми стихирных гласов для клиросных певчих и регентов.

## Возможности
- 🎧 **Тренажёр партий**: тренировка определения гласа по отдельной партии (Сопрано, Альт, Тенор, Бас) или случайной из всех.
- 🎯 **Интерактивная проверка**: 8 кнопок гласов (с поддержкой горячих клавиш 1–8), мгновенная подсветка правильного ответа при ошибке.
- 👥 **Сравнение с хором**: возможность в один клик прослушать звучание того же гласа со всеми партиями вместе (`ALL-N.mp3`).
- 📚 **Учебный раздел**: подробный справочник по всем 8 гласам с богослужебными текстами стихир (на «Господи, воззвах»), ударениями, попевками и рекомендациями для каждой партии.
- 📊 **Статистика**: подсчёт правильных/неправильных ответов, точности в процентах, текущей и рекордной серии побед, успеваемости по каждому гласу.
- 🔊 **Умное воспроизведение**:
  - Поддержка готовых файлов MP3 в папке `public/audio/` в формате `X-N.mp3`.
  - Возможность мгновенной загрузки файлов перетаскиванием прямо в браузере (сохраняются в IndexedDB).
  - Встроенный 4-голосный синтезатор московского обихода (Web Audio API), звучащий при отсутствии MP3.

## Структура файлов аудио в `public/audio/`
Файлы именуются по схеме `X-N.mp3`:
- `S-1.mp3` ... `S-8.mp3` — Сопрано
- `A-1.mp3` ... `A-8.mp3` — Альт
- `T-1.mp3` ... `T-8.mp3` — Тенор
- `B-1.mp3` ... `B-8.mp3` — Бас
- `ALL-1.mp3` ... `ALL-8.mp3` — Полный хор (все партии)

## Запуск локально
```bash
npm install
npm run dev
```

## Развёртывание на GitHub Pages
1. Создайте репозиторий `zapevy-stikhirnykh-glasov` на GitHub.
2. Скопируйте аудиофайлы в папку `public/audio/`.
3. Отправьте проект в репозиторий:
```bash
git init
git add .
git commit -m "feat: Тренажёр запевов стихирных гласов"
git remote add origin https://github.com/ВАШ_ЛОГИН/zapevy-stikhirnykh-glasov.git
git branch -M main
git push -u origin main
```
4. В настройках репозитория (Settings → Pages) выберите **Source: GitHub Actions**. Проект развернётся автоматически!
